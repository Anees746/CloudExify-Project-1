# Personal Expense Tracker

A simple beginner-friendly Python project for tracking daily expenses.

## What it does
- Add new expenses
- View all expenses
- See spending by category
- Filter expenses by category
- Delete expenses
- Save expenses to a file

## How to run
1. Open the project folder in Python.
2. Run the file:
   ```bash
   python month1.py
   ```

## Files
- `month1.py` - main program
- `expenses.txt` - saved expense data
